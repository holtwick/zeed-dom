# AGENTS.md

zeed-dom is a lightweight offline DOM for Node.js, Bun and browsers: HTML/XML parser, virtual DOM, CSS selectors, JSX runtime and serializers (HTML, Markdown, plain text, safe HTML).

## Layout

- `src/` holds the sources, with the tests next to them as `*.spec.ts` / `*.spec.tsx`. Entry points are `src/index.node.ts` and `src/index.browser.ts`.
- `test/` holds benchmarks, `files/` the real-world pages for the golden tests.
- `docs/` is generated by typedoc, do not edit it by hand.

## Commands

- `pnpm test` runs the suite on Node.js, `pnpm test:bun` on Bun, `pnpm test:browser` in Chromium, Firefox and WebKit.
- `pnpm check` type checks, `pnpm lint` / `pnpm lint:fix` runs ESLint (`@antfu/eslint-config`).
- `pnpm perf:compare` regenerates the benchmark numbers in PERFORMANCE.md.

## Conventions

- The public API (exports, classes, methods, type signatures) stays stable. Behavior changes should move towards what a browser DOM does.
- Parsing and DOM operations must stay linear and must not recurse, so large or hostile input can neither hang nor overflow the stack.
- Commit messages use conventional prefixes: `fix:`, `perf:`, `test:`, `docs:`, `chore:`.

## CHANGELOG.md

- Version headings carry only the version number, e.g. `## 0.21.0`, never a marker like "(unreleased)", even before the release.
- Entries are written for users of the library: what changed and why it matters, not which files were touched. Breaking or noticeable behavior changes get their own `### Changed: …` section.
